WIKIGNOME v1.0 PREVIEW

Upload index.html, style.css, app.js, and residents.json together to a GitHub Pages repository root. Open its GitHub Pages URL.

This release includes 63 resident entries, searchable directory, mobile-responsive Wikipedia-inspired interface, article pages, random article, and proposed-character notices.

IMPORTANT: This first version uses condensed public-facing summaries drawn from the Notion registry, not every original continuity note. It deliberately excludes internal editorial notes and personal information. Portraits are placeholders. The Notion publication statuses were not changed.

To edit biographies, update residents.json. The site is static and does not automatically synchronize with Notion.
