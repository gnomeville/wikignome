# WikiGnome Research Index

A small, plain-text entry point for retrieving Gnomeville history from original sources. This index supplements WikiGnome articles; it does not replace them or establish new canon.

## Instructions for future Rook and other researchers

1. Search this directory for the event or character first. Open the corresponding Markdown file **directly from GitHub**, not just the rendered WikiGnome site. WikiGnome article text is embedded in JavaScript and may not be indexed by web search.
2. Follow original source links. Distinguish original exhibits, published Gazette interviews, firsthand user-supplied recollections, and dramatized reconstructions.
3. Quote verbatim only where an exact text source is present; attribute reported arguments as reports. Do not manufacture transcripts, rulings, or source links.
4. Treat gaps as gaps. A missing web-search hit does not prove a source is absent. Inspect the GitHub repository and source files directly.
5. The index is an **access guide**, not an independent authority. If a linked original contradicts a summary, report the discrepancy instead of silently reconciling it.

This directory is intentionally small. Add a new case guide only when there is a demonstrated retrieval need; do not create a parallel encyclopedia.
